# taiko-drums-opus-48

Japanese taiko / festival drum hits and loops. Mix of Taira Komori's Japanese drum recordings (pack 13549, CC-BY) and Vanyamba's Taiko Drum Waveform Stereo C3 (pack 29493, CC0).

## About

This repo holds **48 kbps Opus previews** for fast streaming in the web DAW.
Opus at 48k delivers near-CD quality at ~35% the size of MP3 128k.

- **Library**: Taiko Drums
- **Files**: 8 Opus previews
- **Bitrate**: 48 kbps VBR
- **Container**: Ogg Opus (.opus)
- **License**: mixed (CC-BY-4.0 + CC0-1.0)
- **Source**: https://freesound.org/people/Taira%20Komori/packs/13549/
- **Branch**: `main`
